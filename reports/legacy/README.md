# Rapports de la version d'origine (archive)

Ces fichiers datent de la première version du projet (26 novembre 2026). Ils sont conservés pour la traçabilité, pas comme résultats.

Plusieurs de leurs chiffres n'ont pas été reproduits, n'ont jamais été mesurés, ou ont été obtenus sur des questions vues pendant le développement. Le détail est dans [`../00_reproduction.md`](../00_reproduction.md) et [`../01_audit.md`](../01_audit.md). Les résultats à jour sont dans [`../FINAL_REPORT.md`](../FINAL_REPORT.md).

Les scripts d'origine qui produisaient ces fichiers (`scripts/generate_slides_charts.py`, `scripts/run_clinical_showcase.py`, `scripts/run_e2e_eval.py`) écrivent encore à la racine de `reports/` s'ils sont relancés.
